# Modern Job Board Theme

WordPress theme for the Modern Job Board marketing landing and demo shell.

Works with the plugin [MartinOrton/modern-job-board](https://github.com/MartinOrton/modern-job-board) and static source [MartinOrton/modern-job-board-website](https://github.com/MartinOrton/modern-job-board-website).

## Local path

Typically activated on the Local WP site at `https://mjb.local`.

## Version

Bump `MJB_THEME_VERSION` in `functions.php` after CSS changes so browsers pick up the new assets.
