Requirements

  • WordPress 6.4 or later
  • PHP 7.4 or later
  • WooCommerce, only if you want to charge employers (Pro and higher)
  • A web server that can block direct access to one folder (Apache and LiteSpeed do this automatically; nginx needs one rule; see File storage and server setup)

Install the plugin

  1. In wp-admin, go to Plugins → Add New → Upload Plugin and upload the modern-job-board zip file. You can also copy the modern-job-board folder into wp-content/plugins/ over FTP or SSH.
  2. Select Activate. Activation creates the folders the plugin uses for [mjb_doc plural lower], logos and photos under wp-content/.
  3. Open Modern Job Board → Shortcodes Setup and select Create Missing Pages. This adds the jobs page, the job form, both dashboards, and the login and registration pages, each with the right block already on it.
  4. Open Modern Job Board → Settings and work through the groups: Job board (listing duration, filters, board mode), People & access (registration approval, spam protection, [mjb_doc lower] privacy), Plans & payments and Integrations. The Settings reference explains every setting.

Check that it works

  1. Add a few job categories, locations and job types under Jobs in wp-admin, so the filters have something to show.
  2. Register a recruiter account on the front end and post a test job with the job form.
  3. Register a candidate account in a private browser window and apply for that job with a [mjb_doc lower].
  4. Back in the recruiter dashboard, open the application and download the [mjb_doc lower].
  5. Try to open the [mjb_doc lower]'s folder directly in the browser, for example https://your-site.com/wp-content/mjb-private/. You should get a 403 Forbidden error. If you can see files, follow File storage and server setup before you go live.

If you are on a paid plan, paste your license key under Settings → License & Plan before you test the paid features. See Plans and license keys.

Updating

Replace the plugin folder (or update from the Plugins screen). Your jobs, settings and accounts are in the database and your files are in wp-content/mjb-private/ and wp-content/mjb-brand/, so an update does not touch them. See Going live and updating for the full checklist.
