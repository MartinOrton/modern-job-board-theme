Webhooks send a JSON message to your own URL whenever something happens on the board, so another system (your ATS, a CRM, Slack through Zapier, your own code) can react straight away.

Set up a webhook

  1. Open Settings → Integrations → Google Jobs & Webhooks.
  2. In Webhook URLs, enter the address that should receive the messages. Use full https:// addresses, one per line; every event is sent to each of them.
  3. In Webhook Secret, enter a long random string. It is used to sign each message so the receiver can check it came from your board.
  4. Save, then submit a test application to see the first message arrive.

Events

Message format

Every message is a POST with a JSON body in the same envelope:

{
  "event": "application.submitted",
  "timestamp": 1722000000,
  "site": "https://example.com/",
  "data": { }
}

data holds the details for that event, such as the application or the job. timestamp is a Unix time in seconds.

Check the signature

When a secret is set, each request carries this header:

X-MJB-Signature: {HMAC-SHA256 of the raw request body, as hex}

Work out the same HMAC on the raw body you received, with your secret, and compare. Reject the message if they differ. In PHP:

$body      = file_get_contents( 'php://input' );
$expected  = hash_hmac( 'sha256', $body, 'your-webhook-secret' );
$signature = $_SERVER['HTTP_X_MJB_SIGNATURE'] ?? '';

if ( ! hash_equals( $expected, $signature ) ) {
	http_response_code( 401 );
	exit;
}

$event = json_decode( $body, true );

Calculate the signature on the body exactly as received, before decoding it. Decoding and re-encoding the JSON changes the bytes and the signature will not match.

Delivery and retries

Reply with any 2xx status to confirm a message. Failed deliveries are queued and retried later, with a longer wait after each failure, so a short outage on your side does not lose events. Because a message can arrive more than once, use the event, the timestamp and the record's ID to ignore duplicates.

Developers can change the body before it is sent with the mjb_webhook_payload filter. See PHP hooks.
