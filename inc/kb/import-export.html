All import and export tools are on Modern Job Board → Tools. The Import Jobs and Export Jobs buttons on the admin dashboard lead there too.

Import jobs

  1. Open Tools and choose a source: a CSV file, an XML file, or the address of a remote XML feed.
  2. Run the import. Jobs are created with their companies, locations, categories and job types.
  3. Check the imported jobs in the jobs console before you publish them widely.

To move from another job board, export its jobs to CSV or XML, or use its public XML feed.

Scheduled imports

Open Tools → Schedules, add a remote feed and choose daily or weekly. The feed is fetched again on that schedule, and the list shows when each feed last ran and how many jobs it imported. Partner feeds go here too.

For security, feed addresses on private or local networks are refused. Use public HTTPS feeds.

Export

  • CSV export takes jobs and applications out for reporting. The jobs console also exports the current list.
  • Export Analytics to CSV downloads the views and applications of each job.
  • Full Board XML Backup downloads the whole board as one file.

Backups

The XML backup is useful for moving a board, but it is not a full backup of your site. Keep normal WordPress backups as well, and make sure they include the database, wp-content/mjb-private/ (CVs) and wp-content/mjb-brand/ (logos and photos). See Going live and updating.
