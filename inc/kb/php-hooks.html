Add code that uses these hooks in a small custom plugin, or in a child theme's functions.php, never in Modern Job Board's own files, which are replaced on update.

Hooks

Examples

Show 20 jobs per page on the jobs list:

add_filter( 'mjb_job_listing_query_args', function ( $args ) {
	$args['posts_per_page'] = 20;
	return $args;
} );

Send a Slack message when someone applies (replace the webhook address with your own):

add_action( 'mjb_application_submitted', function ( $application_id ) {
	wp_remote_post( 'https://hooks.slack.com/services/…', array(
		'headers' => array( 'Content-Type' => 'application/json' ),
		'body'    => wp_json_encode( array( 'text' => 'New application #' . $application_id ) ),
	) );
} );

Add a salary to every job's structured data:

add_filter( 'mjb_job_schema', function ( $schema ) {
	$schema['baseSalary'] = array(
		'@type'    => 'MonetaryAmount',
		'currency' => 'ZAR',
		'value'    => array( '@type' => 'QuantitativeValue', 'unitText' => 'MONTH' ),
	);
	return $schema;
} );

Check the number of arguments each hook passes in the plugin's code before you rely on more than the first one.
