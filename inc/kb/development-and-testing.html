These commands are for working on the plugin's source code, from the root of the plugin repository. They need PHP and Composer.

Test on a copy of your site

Always try new versions and custom code on a staging or local copy first. On a copy you can force a plan without a license key:

define( 'MJB_LICENSE_PLAN', 'business' );

and block search engines under Settings → Reading.

Translations

Modern Job Board is translation-ready. Translations use the modern-job-board text domain, and composer make-pot builds the template translators start from.
