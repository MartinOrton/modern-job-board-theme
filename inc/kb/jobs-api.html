The jobs routes return published jobs only. No authentication is needed, so they are safe to call from browsers and other sites.

List jobs

GET /wp-json/mjb/v1/jobs?search_keywords=engineer&search_location=remote&per_page=10&page=1

The response is an array of jobs. The X-WP-Total and X-WP-TotalPages headers give the totals.

[
  {
    "id": 42,
    "title": "Senior Web Developer",
    "link": "https://example.com/jobs/senior-web-developer/",
    "date": "2026-07-20 10:00:00",
    "featured": false,
    "company": "Acme Corp",
    "location": "Remote",
    "type": "Full-time",
    "category": "Engineering",
    "excerpt": "Build modern job board experiences…"
  }
]

Custom field values are included with each job when you use custom fields (Pro).

Search with a readable path

This route mirrors the board's readable search URLs, so you can turn a board URL into an API call by adding the same path:

GET /wp-json/mjb/v1/jobs/search/in/remote/category/engineering/type/full-time/

The path is made of segments for location (in/…), category (category/…), type (type/…) and keyword. Without a path, GET /wp-json/mjb/v1/jobs/search works like the list route with query parameters.

Example: show the latest jobs on another site

fetch( 'https://example.com/wp-json/mjb/v1/jobs?per_page=5' )
  .then( ( response ) => response.json() )
  .then( ( jobs ) => {
    jobs.forEach( ( job ) => console.log( job.title, job.link ) );
  } );
