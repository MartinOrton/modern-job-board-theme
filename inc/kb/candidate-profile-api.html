These routes act as a signed-in candidate and only ever return that candidate's own profile.

Read the profile

GET /wp-json/mjb/v2/candidate/profile
{
  "id": 15,
  "email": "seeker@example.com",
  "first_name": "Sam",
  "last_name": "Lee",
  "headline": "Product Designer",
  "resume_id": 90,
  "resume_url": "https://example.com/?mjb_download=resume&…"
}

Update the profile

Update one or more of first_name, last_name and headline. At least one is required.

PATCH /wp-json/mjb/v2/candidate/profile
curl -X POST -u "candidate:xxxx xxxx xxxx xxxx" \
  -H "Content-Type: application/json" \
  -H "X-HTTP-Method-Override: PATCH" \
  -d '{"headline":"Senior Product Designer"}' \
  "https://example.com/wp-json/mjb/v2/candidate/profile"

[mjb_doc plural] and photos are uploaded in the candidate dashboard, not through the API.
