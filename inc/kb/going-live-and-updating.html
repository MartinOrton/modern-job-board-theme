Launch checklist

  1. Upload and activate the plugin on the live site. Activation creates the storage folders and their protection files.
  2. On nginx, add the deny rule for wp-content/mjb-private/. See File storage and server setup.
  3. Open Shortcodes Setup and create any missing pages.
  4. Enter your license key under Settings → License & Plan, if you have a paid plan.
  5. Set up SMTP so emails arrive. See Email notifications and templates.
  6. Add your Google Maps and reCAPTCHA keys if you use them.
  7. Make sure search engines are allowed: Settings → Reading → Search engine visibility must be unticked on the live site. The admin dashboard warns you if it is not.
  8. Set up your page cache exclusions. See Caching and CDNs.
  9. Run a test: browse jobs, apply with a [mjb_doc lower], download the [mjb_doc lower] as the recruiter, and check that the private folder returns 403.

Do not leave define( 'MJB_LICENSE_PLAN', … ) in the live site's wp-config.php unless you mean to. It overrides the license key.

Updating the plugin

  1. Take a backup first (see below).
  2. Replace the plugin folder, or update from the Plugins screen.
  3. Do not delete wp-content/mjb-private/ or wp-content/mjb-brand/. An update never touches them.
  4. Test one [mjb_doc lower] download and check that the private folder still returns 403.
  5. Clear your page cache after a major release.

Everything you have set up, including jobs, applications, accounts and settings, is in the WordPress database and survives an update.

Backups

Make sure your backups include:

  • the WordPress database;
  • wp-content/mjb-private/ ([mjb_doc plural lower]);
  • wp-content/mjb-brand/ (logos and photos).

Many backup plugins skip folders they do not recognise, so check that these two are included. Keep backups somewhere other than the web server, and remember that [mjb_doc plural lower] are personal information: protect your backups as carefully as the site.
