The Shortcodes Setup screen creates these pages for you. If you prefer to build them yourself, create a page and add the block, or paste the shortcode into a Shortcode block.

Recommended pages

The company directory does not need a page: it is built in at /jobs/companies/, and each company gets its own page there.

Pages the plugin creates for you

Open Modern Job Board → Shortcodes Setup. The screen lists each page the board needs and whether it exists. Create Missing Pages adds only the ones that are missing; it never replaces a page you have edited.

Keep each block on one page only. The plugin finds its pages by the block or shortcode on them, so two job forms on two pages can send links to the wrong one.

Add the board to your menus

Three shortcodes are made for menus and headers. Each one shows the right link for the visitor:

  • [mjb_job_seeker] shows Log in and Register to visitors and links to the candidate dashboard once they are signed in. Add variant="mobile" for a mobile menu drawer.
  • [mjb_recruiter] does the same for recruiters.
  • [mjb_post_job] links to the job form. On a careers site the job form sends visitors to the jobs list instead.

If your theme's menu cannot run shortcodes, add normal menu links to the Jobs, Post a Job and dashboard pages under Appearance → Menus.

Job board URLs

The jobs page uses readable search URLs built from the filters, for example /jobs/in/remote/category/engineering/. Each job lives at a path built from its location and title. These URLs work out of the box; if a job or search page returns a 404 error after you change the jobs page, go to Settings → Permalinks and select Save Changes to refresh WordPress's URL rules.
