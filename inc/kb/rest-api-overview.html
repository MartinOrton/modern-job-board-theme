Modern Job Board has a REST API for connecting your board to other systems: an applicant tracking system, a mobile app, a reporting tool or your own code. It is part of the Business plan; on other plans the routes are not registered.

Two versions

Two more routes live under v1 but have their own rules: Job ingest uses a shared secret instead of a user, and Recruiter MCP uses the JSON-RPC protocol for AI assistants.

Conventions

URLs

All routes are under your site's address. In the examples, replace https://example.com with your own site, without a trailing slash:

https://example.com/wp-json/mjb/v1/…
https://example.com/wp-json/mjb/v2/…
https://example.com/feed/job-listings

The public job search uses the same filters as the board's readable search URLs (default base /jobs/), and v1 also accepts a path-style search that mirrors them.

Request and response format

Requests and responses use JSON in UTF-8. Send Content-Type: application/json with a request body.

Updating with PATCH

Update routes use PATCH. If your HTTP client or server cannot send PATCH, send POST with the header X-HTTP-Method-Override: PATCH.
