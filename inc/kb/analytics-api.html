GET /wp-json/mjb/v2/analytics

Returns a performance summary for the signed-in recruiter: totals across their jobs, and one row per job.

curl -u "recruiter:xxxx xxxx xxxx xxxx" "https://example.com/wp-json/mjb/v2/analytics"
{
  "totals": { "jobs": 3, "views": 120, "applications": 14, "conversion_rate": "11.7" },
  "jobs": [ ]
}

Views are all-time totals. The board does not keep a day-by-day history, referrers or clicks, so the API cannot report trends over time. Repeat views by the same visitor within an hour are counted once.
