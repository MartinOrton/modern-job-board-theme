The ingest routes let an agency ATS or a multiposting tool such as Broadbean push jobs straight onto your board. They accept the field names those tools commonly use and create or update the job.

Switch it on

  1. Open Settings → Integrations → Job Ingestion & Backfill.
  2. Enter a long random Ingestion webhook secret and save. While it is empty, the routes reply 403 mjb_ingest_disabled.
  3. Give the secret and the route address to whoever sets up the ATS.

Authentication

Send the secret in the X-MJB-Ingest-Secret header (recommended), or as a secret field in the JSON body. A wrong secret gets 401 mjb_ingest_auth. These routes do not use a WordPress user.

Create or update one job

POST /wp-json/mjb/v1/ingest/job
curl -X POST "https://example.com/wp-json/mjb/v1/ingest/job" \
  -H "Content-Type: application/json" \
  -H "X-MJB-Ingest-Secret: YOUR_SECRET" \
  -d '{
    "title": "Senior Developer",
    "description": "Build modern job boards…",
    "company": "Acme Corp",
    "location": "Remote",
    "external_id": "ATS-1042",
    "apply_url": "https://example.com/apply/1042",
    "job_type": "Full-time",
    "status": "publish"
  }'

If a job with the same external_id (or id or reference) already exists, it is updated instead of duplicated. Always send your ATS's own job reference so updates land on the right job.

Fields

Import many jobs at once

POST /wp-json/mjb/v1/ingest/batch

Send an array of job objects, or { "jobs": [ … ] }, with the same secret. Each job is handled exactly like the single route. A batch can hold up to 50 jobs; split larger feeds into several requests.

When a search finds nothing

Under Job Ingestion & Backfill you can also choose what visitors see when a search returns no jobs: a message of your own (Backfill message) or a link to a partner job site (Backfill partner URL).
