Recruiter MCP lets a recruiter connect an AI assistant that supports the Model Context Protocol (MCP) to the board. The assistant can then list and update their jobs, review applications and edit their company, in plain language, within the same limits as the recruiter dashboard.

POST /wp-json/mjb/v1/mcp

The route speaks JSON-RPC 2.0 with the methods initialize, tools/list and tools/call. It is only registered on plans that include the REST API.

Who can use it

Every call must come from a signed-in user with the recruiter (employer) role. Candidates, visitors and administrators who are not recruiters are refused. Results are limited to that recruiter's own jobs, the applications to those jobs, and their company. There is no tool for candidate logins or for checkout.

Use an application password for the recruiter's account when you connect the assistant.

Example

curl -u "RECRUITER:APPLICATION_PASSWORD" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"list_my_jobs","arguments":{}}}' \
  "https://example.com/wp-json/mjb/v1/mcp"

Tools

Start a new assistant connection with list_my_jobs and get_recruitment_funnel_summary: they give it the context for most follow-up questions.
